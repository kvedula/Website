# Kamesh Vedula — Personal Site

Single-page portfolio for [kameshvedula.com](https://kameshvedula.com).

## Develop

```bash
npm install
npm run dev
```

## Build & deploy (GitHub Pages)

```bash
npm run build
npm run deploy
```

`deploy` publishes the `build/` folder to the `gh-pages` branch. The custom domain CNAME should already point at that branch.
